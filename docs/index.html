OpenTPU-Benchmark

The Google TPU microbenchmark suite ported from OpenCL-Benchmark, targeting Cloud TPU v5e, v4, v5p, v6e and PJRT/JAX backends.

⚡ Quick Run in Google Colab & Linux

Run directly in any Google Colab notebook cell with TPU runtime attached (or directly in a Cloud TPU VM bash shell):

!curl -sSL https://kreier.github.io/OpenTPU-Benchmark/run.sh | bash

Or via pip:

!pip install -q --no-deps git+https://github.com/kreier/OpenTPU-Benchmark.git
!opentpu
